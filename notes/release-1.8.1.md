Nioh 3 Engine Fix 1.8.1

Fixes from 1.7.90 that 1.8.0 missed: Return to where I was (no soft-lock), infinite health stays on after Return/Yamagata, Boss Match keeps your Training vetoes/repeats, Frame meter switch. Soul core transformations + toggle unchanged.

Install is the same as 1.8.0. On Windows, run Nioh3-Setup.exe. On Linux, Steam Deck, or ROG Ally, run Nioh3-Setup-Linux.pyz. The fresh-install zip includes the loader, the mods, and the default settings.

This file is the hotfix note for the v1.8.1 release candidate. It is not published until the human says so.
