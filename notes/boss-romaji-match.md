# Boss romaji match
Sources: GameWith (gamewith.jp/nioh3/542341, 542334) for Japanese names/readings; GamingBolt 81-boss guide for English names.
Both were read via summarising fetches, so treat "exact" as name-match only; "likely" = inferred from game/history knowledge.
GameWith's reading of Ibaraki as "からき" is a typo for いばらき.
Unmatched: soranaki, boshitsuki, maria, toragozen, naoyoshi, hanbe, yodomi, genshin, morihide, hyakuman, saigo.
Not verified against in-game text. DLC names (chuya/shosetsu, jube) are inference.
