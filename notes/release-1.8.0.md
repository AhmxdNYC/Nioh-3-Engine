Nioh 3 Engine Fix 1.8.0

Soul core transformations are in this update. D-pad left or down turns you into that soul core's yokai: smoke covers the change on the way in and on the way out, you can cancel any attack into the form, the yokai faces the way you were facing, and the form ends right after its last hit. It does not start while you are in the air. It works for every soul core.

Player settings has Soul core transformations. On uses the new forms. Off is the game's original soul cores. The switch applies on the next use.

Install is one step. On Windows, run Nioh3-Setup.exe. On Linux, Steam Deck, or ROG Ally, run Nioh3-Setup-Linux.pyz. The fresh-install zip also has the loader, the mods, and the default settings, so a new install does not depend on copying files by hand.

The Linux updater no longer treats another program that merely mentions Nioh 3 as the game still running, so it no longer hangs on "close Nioh 3" after the game is closed.

Your settings files are kept when you update. New settings start with soul core transformations on.
