# Boss duel flow in the mission scripts (static, 2026-10-08; game not run)

Tools: `re\scripts_re\lfm_disasm.py` (disassembler, stdlib; `py -3 lfm_disasm.py <12-hex-prefix> [--calls|--stmts]`), `re\scripts_re\boss_script_args.py` -> `notes\boss-script-args.csv` (4918 rows: BGM/RTM/boss natives with args, for all 110 archive_09 scripts that call `Mission::BossBattleMode`). Validated: all 110 scripts decode linearly to EOF, every rel32 jump (ops 05/22/24/30/31/48/49, base = insn_off+6) lands on an instruction start; native-call semantics cross-checked (below).

## Format corrections to `boss-fights.md` s7
- Name table entry = `u16 len, u32 hash, name[len], \0` (len excludes the NUL). Sym table follows (`nameIdx,id,kind`, id = idx+1).
- Code start = the function-table op `35 00 <u16 nSyms+1>` (found by signature; the "u32 size" before it is not reliable). That table is 8 B/entry `{u32 codeoff, u16 kind(5 defined/6 extern), u16 id}`.
- Extra operand sizes: `0x2d` u32 (float const), `0x3a` u16. `0x2f` = u16 immediate (a **string-pool offset** for `Debug::PrintString`, not an int). `0x2c/0x2e` = inline literal, `u16 n + n*u32`: 0x2e = float vector, 0x2c = `[hash, tag, extra]` id literal (see BGM). `0x15/0x16` = bool T/F. `0x29` = i32 imm. Valid opcode set (from dispatcher 0x13A830): 1-0x13,0x15,0x16,0x19,0x1b,0x1c,0x1d,0x1f,0x22-0x44 (minus 0x42),0x49,0x4a,0x4c-0x4e,0x50-0x52 (0x52 = stop).
- **Off-by-one trap**: `CALL_NATIVE` (0x1b) operand = sym **id** (entry = operand-1); `CALL_FN` (0x1f) and `FN_ENTRY` (0x3b) operands are 0-based entries. Proof: `PUSH 395; T; CALL` resolves to SetMissionFlag only with -1 (flags 392-396 are the MoveToFixedPosition flags); the first native in the duel flow becomes `Duel::GetBossPlacementID` (a boss id stored in a local) instead of IsAliveBoss; `Function::CreateClearGadget` body = SetMissionClearFlag/EndClearGadgetAccessWaitMode/OnceOnlinePlayEnd. Counts in `boss-bgm-events.csv` come from the name table (usage), not calls, so they differ (PlayBossBGM: 82 calls in 53 scripts here).
- Calling convention: `op03` starts a statement, constant args are pushed right before the call (`03 29 imm CALL`), results are stored with `3d kind idx`; locals are `kind=1`. Nested calls and short-circuit jumps make code order differ from execution order, so arg tokens are best-effort (empty args can mean args come from an earlier push).

## How the boss is chosen: it is NOT in the script
All 110 scripts embed the same library function chain (99 byte-identical native sequences; 11 variants):
- `Function::DuelCommonFlowAnyRange()` takes **no arguments**. Called from the entry function (`fall_prevent_player`/`fall_prevent_master`/`takashima_voice`/numbered `?NNN` user fns) between `Mission::UpdateSetup` and `Mission::WaitUpdateSetup`.
- Its first call is `boss = Duel::GetBossPlacementID()` (zero args, result in local v7; 110/110 scripts, and again in `CheckAndCloseMultiplayByMultiplayProhibitPeriod`). So the id is resolved **engine-side** per mission (stage placement data), never a script constant.
- Then, all keyed on that id: `Character::IsKneelDownFlag/SetInteractionActiveFlag/AlgoActiveFlag/RequestActionTrans(boss,150)/IsAwareFlgAnyPlayer(boss)`, intro `Camera::RequestScriptCamera` with `Character::GetCharacterBasePosition` boxes (literals), `Function::DuelCommonFlow(boss)`, `Mission::BossBattleMode(boss)`, `Duel::IsAliveBoss()` polling, `Mission::BossBattleModeEnd()`, `Function::MoveToWayPointStart/EndMissionClearState`, `Time::Wait1(180)`, `UI::RequestMissionClearEffect`, `Time::Wait1(120)`, `Function::WaitClearGadgetAccess(evtNo, boss)`, `SetOnlineEventNumber`, `CreateClearGadget`, `Mission::EndNoWarpMode/EndBlockadeMission`. A compare of the boss id with literal **58** (v7==58, op0a) selects a branch (jumps straight to DuelCommonFlow, skipping the intro); meaning unverified.
- `DuelCommonFlow(boss)` = `WaitPlayerPrepareDuel(boss, 800.0f)`: waits on `Character::IsEnterPlacementBoxGroupOne(boss, ..)` i.e. **the boss placement id doubles as the PlacementBox group id**, `Character::GetPlayerLength(boss) < 800`, `Duel::IsAliveBoss()`, then `Character::SetAwareFlg(boss)`.
- No mission-parameter or lookup table is read by the script for this; `Mission::GetMissionID()` is called but only inside the duel flow as a compare. Native bindings to trace in the EXE: `Duel::GetBossPlacementID` (the source of truth for the id), `Duel::IsAliveBoss` (no arg: uses the same implicit boss), `Mission::BossBattleMode`.
- Script-specific parts only add events around this (names like `sub_event_boss_battle_start_*`, `*_wave_battle_*`, `kitan_NN_*`, `play_EVxxxx`).

## BGM and RTM args (`boss-script-args.csv`, columns script,native,args,ids_hex,fn,code_off)
- **BGM ids are 32-bit hashes, not small ints.** `Sound::PlayBossBGM` 82 calls/53 scripts, 79 with a constant: either `PUSH_I32 hash` (e.g. 0xCFAB3684 -> -810862972 printed signed; `ids_hex` normalises) or a 12-byte inline literal `[hash, 0x7c0b0783, 0]` (39x; 0x7c0b0783 is a constant type tag, hash = first word). Same hash space across forms (cfab3684 appears as both). A few use small ints (e.g. 396,492 etc. in older rows were mis-resolved natives; ignore pre-fix output) or locals (`v2.1`).
- `Sound::PlayMissionBGMAndState` (124 calls/29 scripts): `[bgmHash, 0000131f|0000d783, 0000001e|0]` (second word = state name tag, third likely a fade/time 30). `Sound::PlayMissionBGM(hash, 30|60)`. `StopBossBGM`/`StopMissionBGM`/`RequestBossBattleBgmEndState`/`SetEnableAutoBossBGM(T|F)` mostly argless/bool.
- Most frequent BGM hashes (ids_hex): 6b79c2ca, 7afe2915, 0efcc25f, c15bd2ea, e7e40a43, 4f795aa4. No match with `kidshash.py --find` over EXE identifiers (81k) so the hash function/name list is still unknown; next try: hash the BGM-box names in archive_03 and the sound bank cue names once found.
- RTM: cutscene ids are constants of `RTM::Request` (228 rows) and `RTM::PlaywithSetFrame` (122) in user fns like `play_EVxxxx`, `door_state_change`; `RTM::StartID` const in 6 rows (e.g. 31305 in `play_EV8302BCDE`); `RTM::SetPlayed(id, F)` in `mission_setup`; theater: `Mission::GetTheaterModeRTMID(v)` in `play_EV2103`. Library wrappers (`RtmContinuous*`, `RtmPlaySubFunction`) pass locals.
- Caveat: fn column = nearest preceding FN_ENTRY marker.
