## Spawn/appearance exclusion (#81988)

Based on learning fix 5a71803b (#6348). The seal's first observed valid non-idle action is treated as appearance. Hit counting waits for a distinct valid non-idle action; idle/invalid reads cannot open the gate. A collision burst already present at bind, before binding, or opening during appearance is excluded for its whole open interval, even if it overlaps the action change. Only fresh subsequent attack bursts update count/open/close timestamps. This supersedes the earlier behavior that counted all child bursts before binding. No core-specific or action-ID table was added; the existing bounded SieRead supplies the action.

Learning still takes the maximum only at verified idle completion with closed collisions or unfired natural despawn. The existing fired guard remains: a last-hit-triggered ghost exit cannot write a learned count later, even if the seal subsequently despawns. Smoke, reveal, ghost/tail code, settings and menu are unchanged from #6348.

Validation: 72 actual tick/settings/menu checks + 357 rematch checks = 429 PASS; sc22 PASS; Release PASS. New 60B86-style fixtures model a bind collider in action 4E57, action change to 4E59 at +0.53 s, and an excluded open interval across +0.70 s. No early exit fires there even with stale known count=1. Fresh attack bursts after the appearance interval count; an unknown core with two genuine bursts learns 2 at idle and exits on the second burst next use. Appearance-only idle/despawn learns nothing; an early last-hit exit never teaches itself. A late bind conservatively ignores earlier unclassified hits and waits for a subsequent action change/fresh burst.
