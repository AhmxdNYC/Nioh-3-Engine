## 1. What the project is, the three mods
- Goal (.handoff/goal.md): make Nioh 3 (Steam v2.02) run better on PC (7600X + RX 9070), PC2 (5600X + RX 6650 XT, slow chipset link) and
  ROG Ally X (Proton) with game-side mods only (no driver/BIOS/hardware tuning, no exe edits, picture must stay the same): lower CPU
  (target 10-20 %), higher fps, faster loads, plus working boss rematch / training. Honest numbers only.
- Nioh3EngineFix.asi (mod/Nioh3EngineFix, ~255 pattern sites): engine patches, in-game mod menu (F10 / Esc x3 / Start x3), overlay,
  frame-gen toggle, VRR, profilers, PSO journal. Hosts the DX12 "hosted" menu used by the other two.
- Nioh3BossRematch.asi (mod/Nioh3BossRematch): "Boss Matches" (user-visible name; old name Rematch). Catalogue of bosses (bosses.tsv),
  Fight now = native mission request or in-place arena swap, Return / Fight-again physical gate object, death/Ki toggles.
- Nioh3Training.asi (source in worktree C:/Users/Ahmad Hamza/nioh3-seqfix/mod/Nioh3Training/src/training.c, ~489 KB, branch pc/seqfix;
  it is NOT in the nioh3-engine repo tree): live arena swap, boss summon anywhere (Load::Character + CreateDynamic), multi-boss slots
  A/B/C.., per-boss stance (idle / fight), aggro, HP/Ki page, move toggles, repeat-move drill, sequences, gold Ki bar, KiBreak
  no-finisher, Player (infinite health) page, Return gate. Exports Nioh3Training_FightNow / _Preload / _Version that BossRematch calls.
  Header comment lists its pipe/cmd file commands (pos, spawn, arena, train, repeat, despawn, kill, gauge, ...).
- Fit: EngineFix = base + menu host. BossRematch = menu/catalogue/fight flow, calls Training exports. Training = the actual spawn /
  swap / drill machinery. All three load as .asi (ASI loader) and log next to the game.
