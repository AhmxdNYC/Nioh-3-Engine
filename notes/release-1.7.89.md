Nioh 3 Engine Fix 1.7.89

Boss Matches now has Fight now rows, so you can start a match from the menu.

Camera rows stay on the menu, but they turn grey until the CamKiProbe add-on is installed. Without that file they do nothing.

The FPS counter can sit in either right corner, and you can change how large its text is.

On Linux, Report opens a window in the game with the snapshot, instead of a desktop folder.

Your settings files are kept. Use the in-game Update page, or Nioh3Updater.
