# Installing the Nioh 3 mod (first time)

1. Go to https://github.com/AhmxdNYC/Nioh-3-Engine/releases/latest
2. **Windows:** download `Nioh3-Setup.exe` and double-click it.
   **Steam Deck / ROG Ally / Linux:** download `Nioh3-Setup-Linux.pyz` and run `python3 Nioh3-Setup-Linux.pyz`.
3. The installer finds Nioh 3 through Steam. It waits for the game to close, backs up your saves and any files it replaces, then installs everything. You don't need to copy anything by hand.
4. Start the game. Open the mod menu with **F10**, or press **Esc three times** (**Start three times** on a controller).
5. **The style meter is off by default.** Turn it on with the "Style meter" row on the menu's Player page.

**Updates later:** use the Update page in the mod menu, or `Nioh3Updater.exe` in the game folder.

**Two notes:**
- **Lyall's Nioh3Fix:** if you already use it, don't install both, because they patch the same code.
- **Windows Smart App Control:** it can block the mod. If nothing happens in game, that's the likely cause.

**Manual install (if the installer won't work):** download `Nioh3-<version>-full-install.zip` from the release and copy every file in it into the Nioh 3 game folder, next to `Nioh3.exe`. In Steam, that's Nioh 3 > Manage > Browse local files.
